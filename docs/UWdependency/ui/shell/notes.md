### Shell items (header, sidebars) — 21 Nov 2026

- Ticker header cog "Customize header": three toggles, Price (last price and change, pre/post-market), Events (upcoming earnings, dividends, analyst ratings, insider trades), Starred pages (a row of tabs for pages starred in the page menu). Not changed.
- The round icon with the "9+" badge at the top right is the account menu, not a notification list: masked e-mail (eye icon not pressed), active subscription (plan name), Account and Subscriptions Settings (not opened), API Dashboard, Changelog (badge), Learn & Help, Log out. Screenshot not filed (account data).
- "Alerts > Open Sidebar": right rail with tabs My Alerts / Preset Alerts, ticker search, filter / mute / settings icons, page arrows, chips All and Stocks, then alert cards. avo's cards on 21 Nov are "Insider Trade" alerts: time, INSIDER tag, ticker, person, bought/sold, shares @ price ($ value), STAKE % change. Buttons Close and "Go to Alerts".
- Preset Alerts tab: chips All, Stocks, Macro, Other; UW's own feed (Trump news + schedule, insider trades, ...).
- "Watchlists > Open Sidebar": tabs Stock Watchlists / Option Watchlists / Portfolio, list select (avo's "AI Veri Merkezi & Yazılım"), table Ticker, Chart (sparkline), Price, Change; "48/10000 tickers"; add-ticker box (not used), Close, Expand, Go to Watchlists.
- Saved Flows (/live-options-flow/saved): the Live Flow page with the "My Flow" source. Empty for avo ("No trades with these filters."). Buttons "Delete Expired" and "Delete All Saved Flow" not pressed.
- Not opened on purpose: /guides and API Docs (external help), /data_shop and /enterprise (sales pages), /trade/pages/settings (account settings), Account and Subscriptions Settings.
