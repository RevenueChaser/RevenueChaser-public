### screeners raw notes (second pass, 21 Nov 2026)

### Options Screener (/options-screener)
One row per option contract for a trading day (day picker; Results 150). Opened in avo's browser with the parameters of the
"Unusually Bullish" preset under the "Custom" chip (watchlist_name "500K OTM Call Buyer Stock Only").
Table columns shown: Last (time), Ticker, Contract, DTE, Stock, OTM, Avg, Low-High, Last, Chg %, Daily %, Vol, OI, OI +/-,
OI +/- %, Prem, IV, IV Chg, % Total, Sweep, Floor, Multi, Bid/Ask Vol, bear/bull Vol, Sector, Earnings.
Columns drawer (15 hidden): View Flow, Options Profit Calculator, Copy Contract Link, View in Contract Look-up, Ticker, Contract,
DTE, Stock, % OTM, % ROC, Avg Price, Low-High, Close, Change %, Daily %, From Low, From High, Volume, OI, OI +/-, OI +/- %,
Days of OI Increases, Days of Vol > OI, Vol/OI, Vol %ile (15d), Prem, Transactions, Delta, Gamma, Theta, Vega, IV, IV Chg,
% Total, % Sweep, % Floor, Multi, 7 Day Bid %, 7 Day Ask %, Bid/Ask Vol, bear/bull Vol, Sector, Earnings.
Toolbar: Filters, ticker filter, Live Flow, Results, day picker, Display, Columns, Info. Panel head: saved filters dropdown
("No saved filters."), bell (alert from filter), disk (save), reset.
"Trade Idea" dropdown: Any, Sell premium, Sell vega, Directional, LEAPs, Cheapies.
Filters: Watchlists; EQUITY TYPE (Stocks, ETFs/ETNs, Indices, ADRs); OPTION TYPE (Calls, Puts);
FILTERS switches (Last Fill >= Avg Price, Volume > OI, Exclude ITM, Exclude Ex Div Tickers, Exclude 0DTE, OPEX only, New Chain);
CHAIN ACTIVITY (Ask %, Bid %, Skew %, Bullish %, Bearish %, 7 Day Bid %, 7 Day Ask %);
CONSECUTIVE INCREASES (Days of OI Inc., Days Vol > OI); AVG (Ticker/30d Avg, Contract/30D Ticker Vol);
AVG (ABSOLUTE) (Ticker 30D Avg Vol, Contract 30D Avg Vol); GREEKS (IV, IV Chg, Delta, Gamma, Theta, Vega, ROC);
CHAIN (Vol %ile (15d), OI, OI Change %, OI +/-, Volume, Premium, Vol/OI, % OTM, % Total, % Multi, % Floor, % Cross, % Sweep,
Change %, Daily %, From Low %, From High %, DTE, Earnings DTE, Floor Volume, Trans, Avg Price, Last, Stock, Spread, Strike,
Marketcap, Earnings Date Gap, Avoid earnings, Earnings week); Market Cap Size; Expiry; Sectors.

### Preset chips = URL path + query parameters (read from the address bar after pressing each chip)
The parameter names match the public API endpoint /api/screener/option-contracts, so every preset can be reproduced by API.
- unusually-bullish: exclude_itm=true; issue_types=Common Stock, ADR; max_dte=183; max_multileg_volume_ratio=0.1;
  min_ask_perc=0.7; min_volume=500; min_premium=250000; type=Calls; vol_greater_oi=true  ("500K OTM Call Buyer Stock Only")
- unusually-bearish: same with type=Puts  ("500K OTM Put Buyer Stock Only")
- unusual-vol-low-iv (Unusual Vol, IV 15-30): min_iv=0.15; max_iv=0.30; min_iv_change=abs(0.05); issue_types=Common Stock, ADR,
  ETF; min_volume=500; order=volume desc
- unusual-vol-mid-iv (IV 31-70): min_iv=0.31; max_iv=0.70; min_iv_change=abs(0.08); rest as above
- deep-conviction-calls: issue_types=Common Stock, ADR; max_diff=0.01; min_diff=-0.12; max_multileg_volume_ratio=0.1;
  min_ask_perc=0.8; min_dte=6; min_premium=500000; type=Calls; vol_greater_oi=true  ("500K ITM Call Buyer Stock Only")
- deep-conviction-puts: issue_types=Common Stock, ADR; max_delta=-0.4; min_delta=-1; max_dte=183; min_dte=6; min_diff=-0.05;
  max_multileg_volume_ratio=0.1; min_ask_perc=0.8; min_premium=250000; type=Puts; vol_greater_oi=true
  ("250K Put Buy Confident Delta Stock Only")
- long-term-calls: issue_types=Common Stock, ETF, ADR; max_avg_price=50; max_multileg_volume_ratio=0.1; min_ask_perc=0.8;
  min_diff=-0.12; min_dte=150; min_premium=1000000; type=Calls; vol_greater_oi=true  ("1M 6mo min Call Buyer Stock or ETF")
- put-sells: exclude_itm=true; issue_types=Common Stock, ADR, ETF; max_avg_price=100; max_multileg_volume_ratio=0.2;
  min_bid_perc=0.8; min_diff=-0.1; min_dte=6; min_premium=250000; type=Puts; vol_greater_oi=true  ("250K Put Sell Stock or ETF")
- cheap-calls: issue_types=Common Stock, ADR; max_avg_price=2; max_dte=30; min_dte=0; max_multileg_volume_ratio=0.1;
  min_ask_perc=0.8; min_diff=-0.02; min_premium=50000; type=Calls; vol_greater_oi=true
  ("50K Call Buyer Cheap Convexity Stock Only")
- bullish-credit-trades: issue_types=Common Stock, ETF, ADR; min_return_on_capital=0.2; min_bid_perc=0.8; type=Puts;
  min_diff=-0.1; vol_greater_oi=true; max_dte=60; min_premium=100000; max_multileg_volume_ratio=0.1
- bearish-credit-trades: same with type=Calls and min_dte=1
State restored afterwards to the original address (Custom chip, Unusually Bullish parameters).
Not pressed: bell, disk, reset, Info, row icons (same components as Live Options Flow).

### Stock Screener (/stock-screener) = "Screeners > Stocks > Table" (second tab Market Map = /heatmaps, /market/maps)
- avo's state (URL): issue_types[] Common Stock + ADR, order marketcap, direction desc, limit 100, min_marketcap 10000000000. Restored after the query-mode test.
- Toolbar: Query (switches to query mode), bell "Create an alert from these filters" (not pressed), Saved menu ("Nothing saved yet", Save as new screen..., Create alert from these filters...), column format menu (built-in: All columns, Earnings, ETF, Fundamentals, GEX, Insiders, Options, Overview (active), Premium, Returns, Std Dev, TA, Volatility), Columns 23, day stepper (Fri, Nov 20), rows (25, 50, 100, 250), pager, Display (Highlight watchlist tickers >), Info.
- Filter sidebar (Reset; group chooser with checkboxes Stock: Price & Volume, Returns, Technicals; Option: Volatility, Option Volume, Premium, Open Interest, Greeks, GEX; Fundamental: Fundamentals, Earnings, Insiders; "Only groups with shown columns", "Show all groups"):
  - Stock: Tickers box, Held by ETF box, Watchlists, Equity type (2 selected), Sectors, Flow groups, Reg SHO.
  - QUICK FILTERS switches: S&P 500 only, Dividend payers, New 52 week high, New 52 week low.
  - PRICE & VOLUME (min/max each): Stock price, Open price, % Change, Intraday %, Stock vol, Stock vol 30D, Stock vol/30D, Mcap / AUM (10B), Short int.
  - RETURNS: 1 day %, 1 week %, 1 month %, 3 month %, 6 month %, YTD %, 1 year %, 5 year %, 1D/1W/1M sigma move, 52W high sigma, 52W low sigma, 52W range %.
  - TECHNICALS: RSI 14, MFI 14, ADX 14, CCI 14, Williams %R, Stoch %K, Stoch %D, Aroon up/down, MACD, MACD signal, MACD hist, ATR 14, OBV, vs SMA 10/14/20/50/200, vs EMA 9/14/20/21/50, vs BB 20 up/mid/low, vs BB 14 up/mid/low.
  - VOLATILITY: IV rank, IV rank 1M, IV pctl 1M, IV pctl 1Y, IV 30D, Impl mv % 30D, Impl move 30D, IV 7D, Impl mv % 7D, Realized vol, VRP.
  - OPTION VOLUME: Vol, Call vol, Put vol, C 30D avg, P 30D avg, Vol / 30D, C vol / 30D, P vol / 30D, P/C ratio, Vol / prev, C vol / prev, P vol / prev, Repeated hits, C vol ask %, C vol bid %, P vol ask %, P vol bid %.
  - PREMIUM: Net prem, Net call prem, Net put prem, Net prem/vol, Net prem/prem, Prem, Call prem, Put prem, Bull prem, Bear prem, Bullish %, Bearish %.
  - OPEN INTEREST: New chains, OI, Call OI, Put OI, OI / vol, OI / 30D, OI change, C OI change, P OI change, OI change %, C OI change %, P OI change %.
  - GREEKS: Dir delta, Dir gamma, Dir vega. GEX: GEX change, GEX change %, GEX put/call, Gamma/1% OI, Delta/1% OI, Charm/1% OI, Vanna/1% OI.
  - FUNDAMENTALS: Buyback yrs, Div raise yrs, ETF flow. EARNINGS: Earnings DTE (0-96), Since ER %, ER RV/impl. INSIDERS: Buys/Sells 3M, 6M, 12M.
- Columns panel "Table setup": tabs Columns (23 of 224), Highlights (cell colour rules per column, e.g. "IV Rank >= 80 in green"; Show highlights checkbox), Custom columns (formula builder: name, formula such as call_volume / put_volume, Insert field, + - * / ( ), Display as Ratio, Decimal places, live preview; "saved in this browser"). Categories with counts; right side = selected columns in order with Pin. Full list with API field names: `stock-screener_all-224-columns.md`. Closed with X, nothing saved.
- Query mode (URL param query=...): query language. Step 1 compare a field to a number (`where call_volume > 500k and iv_rank > 50`; operators > >= < <= = != between..and, in (A, B); numbers 1000, 1_000, 1k, 2.5m, 10b, 2million, 5% = 0.05, 14d 2w 3mo 1y; and / or / not / parentheses). Step 2 compare two fields (`call_volume > put_volume * 2`). Step 3 math and functions (+ - * /, abs, min, max, sqrt, ln, log, pct(a,b)). Step 4 scope prefix (`@Technology where marketcap > 10b and ytd_perc > 20%`; @etf @stock @index @adr; `#"My watchlist" where ...`). "Filters" button returns to the sidebar and clears the query.
- API: /api/screener/stocks takes the same field names as min_/max_ params; the query language is also exposed by the UW MCP (stock_screener_query_language). Custom columns and highlights are browser-side only.

### Sectors (/flow/sectors) — reached only through the Screeners breadcrumb dropdown (not in the left nav). Tabs Flow | Watchlists
### Flow tab
- Table: Ticker (SPY + XLP, XLV, XLE, XLU, XLRE, XLF, XLB, XLC, XLY, XLI, XLK), Sector, Last Price, Change, Vol, (30d avg), Call Vol, (30d), Put Vol, (30d), bear/bull Prem bar, In/Out Flow mini bars, Day Range, 52w Range.
- Row expand shows the ETF's holdings: Ticker, Name, Last Price, Change, Vol, Call Vol, Put Vol, Weight, bear/bull Prem, Day Range, 52w Range, Earnings (days). Expanded XLP and collapsed.
- "<Sector> Market Tide" chart with sector select (Technology; list did not render in the shot): sector ETF price, Daily Put Premium, Daily Call Premium, Volume. "Top <Sector> Tickers by Net Premium": Ticker, Net Premiums, Rank 31D, Net Call, Net Put.
- Relative performance chart of SPY + 11 sector ETFs: Zoom 1m, 3m, 6m, YTD, All; date range inputs; checkbox per ETF; "COMPARE TO SYMBOL" opens a ticker input (not used).
- API: /api/market/sector-etfs, /api/market/{sector}/sector-tide, /api/etfs/{ticker}/holdings, /api/market/top-net-impact.
### Watchlists tab (URL tab=watchlist) — "Sector Watchlists: Curated Stock Baskets"
- Basket select: Cybersecurity, Commodities, AI, China, Travel and Leisure, QQQ (Nasdaq 100), SPY (S&P 500), Semiconductors, Losers, Gainers, Communication Services, ... (list scrolls). Session toggle PRE | REG | POST.
- Columns: Last Trade (GMT+1 / UTC), Ticker, Last Price, Change, % Change, Volume, Avg Vol (30d), Marketcap, Day Range, 52w Range, Earnings Date (several columns empty on Saturday).
- UI-only: the curated baskets are not in the public API.

### Performance (/ticker-performance) — "Ticker Performances" (also only in the breadcrumb dropdown)
- Filters: reset, Filter Tickers, Watchlists, switches Hide etfs, S&P 500 only, Has options, Sectors select, Mcap/AUM min-max, Results per page 50.
- Columns: Ticker, Name, Last, 1D, 1W, 1M, 3M, 6M, YTD, 1Y, 5Y, Last earnings (days), Since earnings, Sector, Mcap/AUM (sort). SPY, QQQ, IWM pinned on top.
- API: same fields exist in /api/screener/stocks (one_day_perc ... five_year_perc, earnings_perc).

### Seasonality (/seasonality) — "Stock Seasonality Screener: Historical Monthly Returns"
- Filters: reset, Filter Tickers, Watchlists, Month select (Jan ... Dec, default current month Nov), Has options, Track Years min-max, Avg %, Median %, Positive %, Mcap/AUM, Sectors.
- Columns: Ticker, Last, Nov % (month to date), 1D %, Positive Closes (% and n/years), Avg, Median, Max, Min, Sector, Mcap/AUM.
- API: /api/seasonality/{month}/performers and /api/seasonality/{ticker}/monthly.
