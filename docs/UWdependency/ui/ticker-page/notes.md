## Notes (what the page shows, buttons pressed, nearest API path)

### Ticker page /stock/<TICKER>/... — second pass 21 Nov 2026 (NVDA used)
Header: ticker picker, section dropdown, last price / change / post-market, "My NVDA trades" (Trading Journal link), "On Watchlist" toggle (NOT pressed: edits the watchlist), date stepper (Fri, Nov 20), gear.
Section dropdown (23 entries):
- STOCK: Overview /overview, Analysts /analysts, Charting /chart, Dark Pool /darkpool, Dividends /dividends, Earnings /earnings, ETF heatmap (greyed for a stock), Financials /financials, Insider transactions /insiders, Institutions /institutions, Risk /risk, Seasonality /seasonality, Shorts /shorts
- OPTIONS: FLEX Trades /flex, GEX/DEX/Vanna/Charm /greek-exposure, Greeks /greeks, Net Premium /net-premium, NOPE/COPE/Ratio /nope, OI Changes /open-interest-changes, Options Chain /option-chains, Options Charting /options-charting, Volatility /volatility, Flow History /options-flow-history
Each entry has a star (favourite) that was not pressed.

### Overview
- Chart with modes: Options Vol, Avg Vol, Net Prem (net call/put premium + net volume through the day, 1D + interval select), Strikes (per-strike cumulative lines; Most Trades / Most Volume / High Net Prem; 1D/3D/7D/14D/30D; interval), Stock (1D/1W/1M/3M/YTD/1Y/5Y/10Y); Compare. Day line: Vol, Prem, Net Prem.
- Side: company blurb, issue type, sector, Upcoming catalysts, Latest news.
- Key Stats: Market Cap, P/E; Stock Vol, Avg Vol, Stock Vol %ile 90d, Opt Vol %ile 90d, Put/Call Ratio; Prev Close, Open, Day Low/High, 52W Low/High; Div Yield, Ex-Div Date, Earnings; Flow: Net Prem, Net Vol, Call Prem, Call Vol, Put Prem, Put Vol, bear/bull bar.
- Highest Volume Contracts (Chain, Last, Low-High, Volume, OI, Bid/Ask Vol %) — this is what the Discord "highest-volume-contracts" channel posts.
- Highest OI Contracts (same columns). Shared Chains (community-shared contracts: Added, Contract, Vol, OI, OI +/- since add, Bid/Ask).
- Historical <ticker> Data table, one row per day: Date, Open, High, Low, Close, % Change, P/C, Volume, C Vol, P Vol, Vol/30D, Bear/Bull, Total OI, % OI%, C OI, P OI, IVR, Volatility 30D, Implied 30D, Volatility 60D, Implied 60D, Net Prem, Total Prem.
- Performance vs SPY/IWM/QQQ (1W..5Y), Daily GEX (price, call gamma, put gamma, net gamma), Options & Off Lit Volume per Stock Price (price group, call vol, put vol, dark pool vol, lit vol, DP %), Insiders, Analysts blocks.

### Insider transactions (/stock/NVDA/insiders) — shots 22-24
- Left card "Insider Stats, last 12 months": Net, Buys, Sells, Exercises, Grants, Tax, Gifts, Other (shares, dollars, trade count).
- Price chart with a marker per insider trade (red down = sale, green up = buy/grant), Open Charts, draw and study icons, ranges 1D 2D 1W 1M 3M 6M YTD 1Y 5Y.
- Table: Ticker, Trade Date, Filing Date, Name (link to the insider), Title, Code (S - SALE, A - GRANT, G - GIFT, F - TAX ...), Security, Shares (#), Price, Value ($), Trans. (number of transactions folded into the row), 10b5-1, Director, 10% Owner, Mcap/AUM. Each row has an expand arrow. Goes back to at least Sep 2024.

- API: /api/insider/{ticker}, /api/insider/transactions, /api/insider/{ticker}/ticker-flow. High relevance for avo's "insider-trades via Form 4" build.
- Row expand (shot 25): the single transactions behind a folded row: Trade Date, Filing Date, Ticker, Name, Title, Trade Type, Security Title, Shares (#), Price, Value ($), Qty Owned After, Stake Chng (% change of the holding), 10b5-1, Director, 10% Owner. "Stake Chng" = shares / (owned after + shares sold), derivable from Form 4.

### Shorts (/stock/NVDA/shorts) — shots 33-35
- Five blocks, each a chart plus (from the second on) a table at its right:
  1. "Short Interest Volume": Short Volume, Total Volume, Short Volume Ratio per day (Time Period select, 6M default).
  2. "Short Shares Available Over Time" (Start Year select) + table Date, Short Shares Avail. (several rows per day, intraday snapshots).
  3. "Failure to Delivers (per SEC)" + table Date, Quantity, Price.
  4. "Borrow Rates" + table Date, Borrow Rate, Rebate Rate.
  5. "Short Volumes (per CBOE)" by exchange (FINRA CNMS) + table Date, Exchange, Short Vol, Total Vol.
- Sources: FINRA daily short volume files (free), SEC FTD files (free, twice a month), shares available and borrow/rebate rate (broker feed; IBKR publishes the same kind of file).
- API: /api/shorts/{ticker}/data, /ftds, /interest-float, /volume-and-ratio, /volumes-by-exchange. Relevance: low to medium; all free sources.

### FLEX Trades (/stock/NVDA/flex) — shots 36-38

- API: /api/flex-options, /api/flex-options/{ticker}, /api/flex-options/market, /api/flex-options/chain/{chain} (checked against public_api_paths.txt). Relevance: low.
