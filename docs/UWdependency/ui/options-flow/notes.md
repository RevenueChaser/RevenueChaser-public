### options-flow raw notes (second pass, 21 Nov 2026)

### Live Options Flow (/live-options-flow)
Opened with avo's saved filter "Ask Flow" and ticker EAT (URL carries every filter as a query parameter:
limit, is_otm, volume_greater_oi, is_multi_leg, max_open_interest, max_dte, excluded_tags[], min_premium, min_volume,
max_price, issue_types[], min_ask_perc, add_agg_trades, watchlist_name, ticker_symbol). Saturday: "No trades with these filters."

Top strip: tabs Live Flow / Interval / 0DTE / Multi; ticker header (price, post-market, sparkline, Volume, Premiums,
Bullish, Bearish bars); "More" menu.
Toolbar: Filters (toggle panel), My Flow, Filter <saved name>, ticker search, Live Flow (play), Prev, Next, Muted (sound),
Results 50, Sort Time, Display, Columns, CSV (not pressed), Info.
Filter panel head: Filters dropdown, bell = "Create an alert from the current filter", disk = save, orange = history/reset,
"Ask Mr. Whale to Filter" (not used, spends credit), ticker box with "Clear tickers", TIME RANGE.

Filter panel fields, in order:
- SIDE show/hide: Bid, Mid, Ask, No Side
- CHAIN ACTIVITY ranges: Ask %, Bid %, Skew %
- OPTION TYPE show/hide: Calls, Puts
- EQUITY TYPE show/hide: Stocks, ETFs / ETNs, Indices, ADRs
- Expiration Dates (multi select)
- Ranges: Premium, Size, Spot, DTE, Volume, OI, Vol/OI, Mcap/AUM, Stock, Strike, Spread, % OTM, Earnings Report (days),
  Earnings Date Gap; buttons "Avoid earnings", "Earnings week"
- TICKER OI & AVG VOL (ADV) [New]: Total OI, 7d ADV, 30d ADV, Size / Total OI, Vol / Total OI, Size / 7d ADV, Vol / 7d ADV,
  Size / 30d ADV, Vol / 30d ADV
- GREEKS: IV, Delta, Theta, Gamma
- FLAG TYPE show/hide: Sweep, Cross, Floor, Normal, Auction
- EXTRA show/hide: China, Volatility, Dividend
- OTHERS switches: Unusual, Volume > OI, Size > OI, Opening trades, Exclude deep ITM, OPEX only, OTM only, Multi-leg only,
  Single-leg only, FLEX only, Exclude FLEX, Today's trades only, Hide Expired, Aggregated trades (moved to Display menu),
  Show Canceled/Modified
- Option Watchlists (select); Universe (Top 50 / Top 100 stocks by option volume, S&P 500, Nasdaq-100, Dow 30, Russell 2000
  top 250, Magnificent 7, Semiconductors SMH, Biotech XBI, Energy XLE, Financials XLF, Regional Banks KRE, Retail XRT,
  Gold Miners GDX, ARK Innovation, China FXI); Stock Watchlists; Investor list holders (+ "Create an investor list");
  Sectors; Industries; Exchanges; Trade Codes

Buttons pressed and what they do:
- Display: checkboxes "Keep aggregated trades", "Add color highlight"; submenus "Highlight watchlist tickers",
  "Highlight watchlist contracts"; "About aggregated trades".
- Columns: drawer "Configure Flow Table", search, "30 hidden columns", reset, "Quote highlight" (No Highlight), drag handles
  to reorder, a Show switch per column. Columns: Info, Save, View Flow, Options Profit Calculator, Copy Contract Link,
  View in Contract Look-up | Side, Contract, DTE, SP (Underlying), % OTM, Moneyness, B T delta, B Qty, Bid, Bid-Ask,
  Mid point, Spot, Ask, A Qty, A T delta, B Qty - A Qty, B T delta - A T delta, Fill vs Spread, Spread Width, Size, Premium,
  Volume, OI, Vol/OI, Vol/OI Bar, Chain Bid/Ask, Shares Equivalent, IV, Delta, Delta Gauge, Theta, Gamma, Vega, Rho, Theo,
  Sector, Industry, Earnings Report, Show (if applicable) Flow Alert, Matched Alert Filters, Investor List Holders, Legs,
  Trade code, Exchange, Flags, Tags.
- Info: drawer "Options Flow Information" (video, contents, side rules, shortcuts, legend, FAQs); full text archived as
  three images live-options-flow_info-text_left/mid/right. Key facts: side comes from fill vs NBBO; sort by Size/Premium
  limits results to >= $25,000 notional or 150+ contracts; saved trades limit 1000; opening trade rule
  "(size) > OI - (volume - size)"; CSV needs Retail Pro.
- More: Volatility, Option chains, Price Calendar, Earnings, Dividend, Quick View (ticker shortcuts).
- Sort: Time, Prem, Size.  Results: 50, 100, 150, 250.
- Filters dropdown: PRESETS (All, Ask Flow, Bid Flow, Big Trades - Ask, Big Trades - Bid, ETF Flows - Ask, Big Multileggers),
  "Shared Filters" link, MY FILTERS (none saved), CUSTOM ALERT FILTERS (none) with "Manage Alerts".
  So "Ask Flow" is a UW preset, not a saved filter of avo's.
- Clearing the ticker shows the feed for all tickers and replaces the ticker header with a market strip (RUT, SPX, VIX, VVIX,
  BTC, Advancers, Decliners, New 52w Highs, New 52w Lows, Week Earnings, Next Week) plus "Flow Status".

### My Flow (/live-options-flow/saved)
Same feed layout for saved trades; empty for avo ("No trades with these filters"). Extra toolbar buttons
"Delete Expired" and "Delete All Saved Flow" (not pressed). Filter selector reads "Select Filter".

### Interval Flow, Contract view (/interval-flow?limit=50&interval=10)
Flow aggregated per contract per 5 or 10 minute window (URL parameter interval=5|10). Sub-tabs Contract / Ticker.
Preset chips: Custom, Ask-side Intervals, Bid-side Intervals, Ask-side ETF Flows, Above-Avg Volume. A chip rewrites the URL
filters (Ask-side Intervals = interval=5, hide_index_etf, min_total_vol_perc=0.4, min_premium=100000, vol_greater_oi,
min_volume=500, max_multileg_volume_ratio=0.3, total_vol_greater_oi, exclude_itm, min_ask_perc=0.55). Clicking "Custom" did not
undo it, so the original URL was reloaded to restore the page.
Toolbar: Filters, Settings (popover "Table Settings": Interval Separators switch), ticker filter, Live Flow, Results 50,
day picker (Previous day / Fri, Nov 20 / Next day), Muted, Display (Highlight watchlist tickers / contracts), Columns, Info.
Panel head: folder dropdown = saved filters ("No saved filters."), bell (alert from filter), disk (save), reset; not pressed further.
Columns (all 25 shown): View Flow, Contract Transactions, Options Profit Calculator, Copy Contract Link, View in Contract Look-up,
Ticker, Contract, DTE, % OTM, % Total Vol, Sweep, Floor, Interval Vol, Vol/OI, Avg Fill, IV, IV Chg (window), Interval B/A,
% Multi, Premium, Total Vol, OI, Total Vol/OI, Total B/A, Total % Multi (+ Earnings).
Filters: Watchlists; EQUITY TYPE (Stocks, ETFs/ETNs, Indices, ADRs); OPTION TYPE (Calls, Puts); Expiry; Sectors;
INTERVAL ACTIVITY (% Total Vol, Volume, Vol/OI, Avg Fill, Spread, Ask %, Bid %, Skew %, bull %, bear %, % Multi, % Sweep,
% Floor, Premium, % OTM); QUICK FILTERS (Interval Vol > OI, Total Vol > OI, Exclude 0DTE, Exclude ITM); CHAIN ACTIVITY (DTE, OI,
Strike); UNDERLYING FILTER (Stock, MC/AUM, Earnings Report, Earnings Date Gap, Avoid earnings, Earnings week);
AVG (Ticker/30d Avg, Inter. Vol/30D Ticker Vol); AVG (ABSOLUTE) (Ticker 30D Avg Vol, Inter. 30D Avg Vol);
GREEKS (IV, Delta, Gamma, Theta, Vega, % IV Change).

% Put, % Sweep, % Floor, % Cross, % Multi, Net Prem, % Volatility Change, % Implied Move Change, % Stock Change);

### 0DTE (/zero-dte)
One screen, no scroll: four "Zero/Weekly DTE Tide" charts (Equity, Index, ETF, All). Each plots SPY price against
Net Put Prem and Net Call Prem with a net volume strip; header line shows time, SPY, Vol, NPP, NCP.
Per chart: moneyness dropdown (All Moneyness, ITM, OTM, ATM; multi-select chips), Expirations dropdown (Weekly, 0 DTE), Info
(dialog explaining net premium / net volume; equities have no 0DTE so weekly only).
"Show Charts" menu: checkboxes Equity Only, Index Only, ETF Only, All (which of the four charts are shown).
Nothing changed. API relation: market tide / net premium ticks exist in the API; the 0DTE split per security type is a UI view.

table (Side Buy/Sell, Contract, Expiry, DTE, Price with bid-ask, Fill vs Spread, Size, Prem, Vol, OI, Delta, Theta, Share eqv),

Filters: Strategy (1-1-2, Box Spread, Call Backspread, Call Butterfly Spread, Call Calendar, Call Condor, Call Diagonal Spread,

### Contract Look-Up (/flow/option_chains)
Lives under the "Watchlists >" strip (Stock Watchlist, Options Watchlist, Investor Lists, Contract Look-up).
Empty state: search box "Contract or Ticker"; left "Bookmarks" list of viewed chains (sort, reset, list icons).
Typing a ticker lists its contracts ranked by volume, each with Vol, OI, OTM %, Multi %, Bid %, Ask %.
Opening a contract (NVDA 125 P 2026-11-20 used as the example; the bookmark it created was removed afterwards):
- Header: company, close, post-market, next earnings; "Show Charts", "Add to Watchlist" (not pressed); icons profit calculator,
  flow for this contract, options chart, alert bell, more (Build strategy with contract, Get link to contract, Copy chain ID).
- Contract chart: Share (not pressed), series dropdown (Bid/Ask, IV, Volume/OI, Exposures, Delta, Gamma, Theta, Vega, Rho, Theo),
  range 1 D, interval 5 min, settings (Sessions GTH / RTH / CURB). Header line: Vol, OI, Avg, Prem, Multi, %OTM, Bid x size, Ask x size.
- Underlying chart tabs: Options Vol (Call/Put Vol, Call/Put Prem, bear/bull Vol), Avg Vol (Volume or P/C against 7 D / 14 D /
  30 D average), Net Prem (net premiums and net volume, 1 min), Strikes (Most Trades / Most Volume / High Net Prem, 1-30 D,
  one line per strike), Stock (price chart 1D..10Y, Compare).
- Historical Volume / OI table for the contract: Date, Vol, OI, OI change, Close, Avg, Vol (30min) sparkline, Bid/Ask, IV,
  Floor, Sweep, Multi, Total Prem, % Total.
- Historical ticker data: Date, Open, High, Low, Close, % Change, P/C, Volume, C Vol, P Vol, Vol/30D, Bear/Bull, Total OI, ...
- Analysis block (Position long/short): Trade-Idea Fit (select a trade idea to score the contract), Probability of Profit,
  Kelly Position Sizing (Full / Half / Quarter), Position Metrics (Odds Ratio, Volatility Adjustment, Margin Factor),
  Profit Probabilities, Risk/Reward Profile (Max Potential Gain, Max Potential Loss, payoff chart), Strategy Identified ("Long Put").
  The two chart areas at the bottom rendered empty at capture time.
API relation: contract history, intraday and flow are in the API (option-contract endpoints); the Analysis block
(probability of profit, Kelly sizing, trade-idea fit) is UI only.

### Net Flow (/option-charts/ticker-flow)
Per ticker and day (opened on AAPL, 2026-11-20). Header: Price, P/C Ratio, Call Volume, Put Volume, Total Daily Volume,
Total Daily Premium.
- "<TICKER> Net Flow" chart: price against Net Put Prem / Net Call Prem with net volume strip; zoom premium axis in/out,
  line/area toggle; "More Options on Ticker Page" link.
- "Top Chains by Volume" table: Chain, Vol, OI, Net Vol, Net Impact (sortable).
- "Net Premium by Expiry" bar chart; metric dropdown: Net Premium, Call + Put Volume, Call + Put Premium, bear/bull Volume,
  bear/bull Premium.
- "Net Premium by Strike" bar chart; strikes range All Strikes / 10 / 25 / 50 / 100; same metric dropdown.
Filter panel (changes what the net numbers are built from): ticker, Date, SIDE (Bid, Mid, Ask, No Side), OPTION TYPE,
Expiration Dates, ranges Premium, Size, Spot, DTE, Volume, OI, IV, Strike, Spread, % OTM; FLAG TYPE (Sweep, Cross, Floor,
Normal); OTHERS (Volume > OI, Size > OI, Opening trades, Exclude deep itm, Otm only, Multileg only, Singleleg only,
Today's trades only, Hide Expired). Panel head: saved filters dropdown, disk (save), reset; not pressed.
API relation: net premium ticks, flow per expiry and flow per strike are API endpoints; the filtered recomputation is UI.

### Flow Alert Rules (/option-flow-alerts/rules) — static definitions page, nine rules
- Sweeps Followed By Floor: min 10 sweeps, then a floor trade with premium >= 100000.
- Repeated Hits / Repeated Hits Ascending Fill / Repeated Hits Descending Fill: trades grouped by option chain within 2000 ms of the first trade, no multi-leg, >= 2 trades, total size >= 100 contracts, total premium > 10K; ascending/descending = fill-price trend.
- OTM Earnings Floor: floor trades grouped by ticker within 1000 s, earnings within 2 weeks, expiry within 90 days, total premium > 250K.
- Low Historic Volume Floor: floor trades by ticker within 1000 s, total volume > historic 3D volume, market cap < 150B, premium > 50K.
- Floor Trade Small Cap (300M-2B) / Mid Cap (2B-10B) / Large Cap (10B-50B): floor trades by ticker within 1000 s, premium > 100K or volume > 1000.
- "Explanation" section: bucket example; several alerts per trade group are by design; each alert links to its triggering trades.
- Columns drawer ("Configure Columns", closes with ">" only): row actions View Flow (on), Options Profit Calculator (off), Copy Contract Link (off), View in Contract Look-up (off); data columns Ticker, Side, Bid-Ask, Contract, DTE, Stock, Spot, Rule, % OTM, Alert Size, Alert Premium, Alert Bid/Ask Prem, Alert bear/bull Prem, Volume, OI, Vol/OI, IV, IV Chg (window), Earnings, Marketcap, Sector. 0 hidden. Search box + reset.
- Rules select: options are the rule names (e.g. SweepsFollowedByFloor); list did not render readable, see rules page for the nine names.
- Row "View Flow" icon (left of time) opens a NEW TAB: Flow Alert Breakdown, /option-flow-alerts/<option symbol>/<alert uuid>. Content: title "STM $25 P 2027-01-15", rule badge (REPEATED HITS), links "Visualize this trade" and "Related flow"; underlying intraday price chart with a dotted line where the rule fired; Technicals block (Expiry, Underlying, Timestamp, Total Prem, Bid Side Premium, Ask Side Premium, Highest % Change, Current % Change, Open Interest, Volume); table "Trades related to this flow alert" with Time, Ticker, Side, Contract, DTE, Stock, Bid-Ask, Spot, Size, Premium, Vol, OI, Vol/OI, Share Eqv, Delta, Vega, IV (%), Code (AUTO...), Flags, Exchange (XBOX...). Tab closed after capture.
- API: alert rows = /api/option-trades/flow-alerts; the per-alert trade list is the same data as option trades for the chain around the alert time (no separate public path seen for "alert id -> trades"; check spec in final pass).
