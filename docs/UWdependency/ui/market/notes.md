## Notes (what the page shows, buttons pressed, nearest API path)


### Daily Reports (/reports) — "Daily Market Report", second pass 21 Nov (report date 20/11/2026)
- Intro: biggest moves in implied volatility and skew across the most actively traded options names, ranked on percentile-based signals, plus top options flow and the day's catalysts.
- Only control: Date picker (20/11/2026). No filters, no export.
- Sections (all static tables):
  1. Biggest up-moves in vol ("Richest implied vol vs realized, by anomaly score"): Ticker, Score, IV %ile, Skew %ile, Inputs (of 5). 25 rows.
  2. Biggest vol crushes ("Cheapest implied vol"): same columns, negative scores.
  3. Biggest skew moves ("Ranked by the 25-delta risk-reversal component"): same columns.
  4. Top options flow ("Biggest tickers by net premium for the day"): BULLISH list and BEARISH list, ticker + net premium (SPY $160.9M ... NVDA $-257.2M).
  5. Unusual options activity ("Biggest unusual contracts (volume > OI, OTM, ask-side)"): Ticker, Type, Strike, Exp, DTE, Vol, OI, Vol/OI, V/OI decile, OI change %, Days Vol>OI, Days OI up, IV, IV change, Premium.
  6. Notable stock movers ("Ranked by how unusual today's volume is vs each name's own 90-day history"): Ticker, Mkt Cap, Close, Vol vs 30d, Stk Vol %ile, Opt Vol %ile, IV Rank, Impl. Move, Call Vol, Put Vol.
  7. Today's catalysts (ET): tagged rows ECON, EARNINGS (with implied move), POTUS, SPLIT, HALT.
- API mapping: the anomaly "Score" and "Inputs (of 5)" are a UW composite, not in the public API (UI-only). Inputs can be rebuilt: net premium = /api/market/top-net-impact or /api/stock/{t}/net-prem-ticks; unusual contracts = /api/screener/option-contracts (vol > OI, OTM, ask side); movers = /api/screener/stocks; catalysts = economic calendar + earnings + halts.
- Date picker: month grid with Clear / Today; past dates selectable (report archive by day). Not changed.

- Chart info icon opens "DAILY MARKET TIDE GUIDE" (formula, important for own build): aggregated PREMIUM = value of options traded at or near the ASK minus value traded at or near the BID, separately for calls (CALL PREMIUM) and puts (PUT PREMIUM). Example: $15,000 calls at ask and $10,000 calls at bid -> call premium +$5,000; $10,000 puts at ask and $20,000 at bid -> put premium -$10,000. Bullish when call premium rises faster / put premium falls faster; bearish the reverse. VOLUME = aggregated call volume (ask minus bid) minus aggregated put volume (ask minus bid).
