### /politics?view=flow (Politics Flow)
- Table: Name, Ticker, Transaction Type (BUY/SELL), Date (transaction), Notification Date (disclosure), Amount (range bucket, e.g. $100,001 - $250,000), Description, Chamber (House / Senate / White House Office), external link to the filing. Sortable: Date, Notification Date, Amount. 50 results per page, Prev/Next.
- Toolbar: Filters toggle, Search Politicians, Live Flow (stream), Muted (sound), Info (no visible panel when pressed).
- Left filter panel: saved-filter folder menu ("No saved filters"), alert-from-filter bell (not pressed: creates an alert), save, reset; Filter Tickers; Filter Tickers by Watchlist; Disclosure time range; Transaction time range; Amounts min-max; Chambers House/Senate/Executive show/hide; Asset Type (stock, options, futures, bond, crypto, other); Sectors; Industries; Marketcap min-max; Affiliation Republican/Democrat/Unaffiliated; Gender Male/Female.
- Executive branch (Trump) filings are in the same feed: Trump's 2026/09 trades notified 2026/11/19.
- Source data: public STOCK Act periodic transaction reports (House Clerk, Senate eFD) + OGE 278 for the executive.

### /politics/sonar ("Unusual Trades" = USONAR)
- "Suspicious Trade Detection Radar". Guide text: USONAR (Unusual Stock Occurrences: News, Alpha, Representatives) flags trades when politicians trade in sectors their committees regulate, especially when: the trade significantly outperforms the market (high alpha), it occurs shortly before market-moving events, the politician sells before a downturn (loss avoidance), there is a jurisdictional conflict with committee assignments.
- Chart reading: left = Democrats, right = Republicans; centre = recent, outer rings = older (3M/6M/9M/12M); top = high gains vs SPY (14-day alpha), bottom = loss avoidance.
- Hover a dot: side panel with politician, party/district, ticker, sector, Alpha (14D) (e.g. Tim Moore SMCI +43.13%), est. amount bucket, execution date, a generated sentence naming the committee conflict, and a Relative Performance chart (ticker % vs SPY % around the trade price).
- UI only: the conflict flagging (committee-to-sector map) and 14-day alpha are UW's derived work; not in the public API paths list.
