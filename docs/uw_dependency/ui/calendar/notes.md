## Notes (what the page shows, buttons pressed, nearest API path)

### /earnings "Anticipated Earnings" (2026-11-21 14:52 Amsterdam)
Views: Calendar View, List View (default), IV View. Link: "Get PDF summary of upcoming earnings via email" (not pressed: sends mail / changes subscription).
List View columns: Earnings (date), PM/AH, Ticker, Name, Price, Change, %, Implied Move (% and $), ø 1D RV, Past reactions (bar sparkline), Stock Vol, Options Vol, OI, Last earnings, Since, Mcap, EPS Estimate, Sector. Session switch: ALL / PM / AH. ~120 rows for the week, sorted by OI.
List View left filters: Filter Tickers; min-max for EPS, Implied Move, Market cap, Option Vol, Open interest, Stock Vol, Since Last ("use 1.00 to represent 100%"); dropdowns Countries (All, US, CN, AR, GR, IL, GB, IE, AU, SG, ...), Sectors (All, Basic Materials, Communication Services, Consumer Cyclical, Consumer Defensive, Energy, Financial Services, Healthcare, Industrials, Real Estate, Technology, ...), Market Cap (All, Micro, Small, Mid, Large, Big). Icons: bell "Create an alert from the current filters" (not pressed), reset.
Calendar View: one column per weekday, sub-columns PREMARKET / TBD / AFTERHOURS, ticker logos; header shows "QQQ: 3 this week / 3% holdings / 1% weight; SPY: 13 this week / 3% holdings / 1% weight". Sort: Open Interest, Market Cap, Options Volume, Stock Volume, Implied Move.
Range picker: weekly ranges (11-16 - 11-20, 11-23 - 11-27 (Current), 11-30 - 12-4, 12-7 - 12-11, 12-14 - 12-18, 12-21 - 12-25).
IV View: scatter "Anticipated Earnings by Implied Movement", top 10 companies per weekday by OI, y = expected move %.
API match: /api/earnings/premarket, /api/earnings/afterhours, /api/earnings/{ticker}. The "Past reactions" sparkline and the QQQ/SPY weight header look UI-only (to verify in the UI-only list).
