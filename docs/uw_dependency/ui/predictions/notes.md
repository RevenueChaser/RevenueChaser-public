## Notes (what the page shows, buttons pressed, nearest API path)

### Predictions ("Unusual Predictions, powered by Polymarket") - raw notes, 21 Nov 2026 ~16:15-16:18 Amsterdam
Own top bar: Unusual Markets /predictions | Smart Money (Overview /predictions/smart-money, Top Traders /predictions/smart-money/top-traders) |
Insiders (Overview /predictions/insiders, Top Markets /predictions/insiders/top-markets) | Whales (Overview /predictions/whales, Trades
/predictions/whales/trades) | API /predictions/api | Watchlists /predictions/watchlists. The menu headers open on hover; a click goes to Overview.
Unusual Markets: table MARKET / OUTCOME / CURRENT (cents) / U-SCORE / INDICATORS (coloured chips) / VOLUME / RESOLVES / CATEGORY; pager;
"Filters" opens a row: Category, Price range (0-100 c), Min volume, Min U-score; search box.
Smart Money: cards per market with a bell curve, Smart Score per outcome and "Smart Gap". Definition (tooltip): "Markets ranked by Smart Gap -
the difference between average Smart Scores of the outcomes. A user's Smart Score measures their past performance relative to other users."
Filters: Categories, Price. Top Traders: USER (wallet) / SMART SCORE / WIN RATE / MARKETS / PNL / INVESTED; Category, Filters, Include Bots.
Insiders: "Potential Insiders on Polymarket", ranked by Z-Score. Definition (tooltip): traders who enter at low prices, make very large trades,
have little account history, rarely trade other markets; high Z = position much larger than average for that market; "only a signal, not proof".
Columns FIRST TRADE / SINCE / MARKET / OUTCOME / Z-SCORE / USER / INVESTED / AVG PRICE / CURRENT / PNL / POSITIONS / WALLET AGE AT TRADE /
RESOLVES / CATEGORY. Filters: category, min invested, min z-score, max avg price, min PnL, max positions, max wallet age. "Include Bots".
"Create Alert" -> popover "Prediction Insider Alert: Set at least one filter to create an alert" + link "Go to Custom Alerts" (nothing created).
Top Markets: "Insider Money Flow by Market" diverging bar chart (No/Alt vs Yes/Primary dollars per market, one block per insider).
Whales: overview cards (market, side, invested, PnL, avg vs now, price line); Trades table MARKET / OUTCOME / INVESTED / AVG PRICE / CURRENT /
CURRENT VALUE / REALIZED PNL / UNREALIZED PNL / OVERALL PNL / WALLET AGE / USER, filters Market / Outcome / User.
API page (/predictions/api): a SEPARATE API from the main UW REST API. Base https://phx.unusualwhales.com/hashdive/api, OpenAPI 3.1 at
.../hashdive/openapi.json, auth = Bearer session token ("grants the same access as your session"; rate limits "match the standard Predictions
plan"). THE PAGE SHOWS THE TOKEN IN CLEAR inside the "llms.txt" block and the Python snippet: both were blacked out before the saved
screenshots; the token was not copied, written or revealed. 44 endpoints in 7 groups:
 Predictions: GET /api/predictions/smart-money, /ticker-signals/{ticker}, /tickers/{ticker}, /unusual-trades
 Markets: GET /api/assets/{asset_id}, /detail_agg, /insider_trades_agg, /liquidity, /ohlc, /positions, /trades, /trades_agg
 Users: GET /api/users/{user_address}, /combos, /score-history, /trades_agg
 Traders: GET /api/traders/screener, /smart-users, /top, /whales
 Insiders: GET /api/insiders
 Search: GET /api/search, /api/search/users (deprecated)
 Watchlists: 20 endpoints (list/create/get/delete/patch/duplicate/follow/unfollow/market-detail/markets add+remove/user-stats/users
 add+remove+patch/feed markets/feed trades/following/public/shared/{slug}/summaries)
Websocket: wss://ws.unusualwhales.com/v2/foo/websocket, channel prediction_watchlist:<slug>, frames phx_join / status / heartbeat / new_msg.
Migration relevance: none for RevenueChaser today (Polymarket analytics; the stock link is /api/predictions/tickers/{ticker}).
Watchlists (/predictions/watchlists): "MY WATCHLISTS (0)"; "New Watchlist" opens dialog Name / Description / Make public / Cancel / Create
(closed with Escape, nothing created). Community watchlists (Insider Moves, Bitcoin Insiders, Ukraine-Russia Watchers) with FOLLOW (not pressed).
Indicator chips in the Unusual Markets table have hover names (Whales, Potential Insiders, Smart Money, plus momentum/time chips).
Clicking a market opens the "Market Analysis" panel (URL stays /predictions; "Open in new tab", "Add to Watchlist" not pressed):
 header (resolves, liquidity, category, rules text with "Read more"); chart toggle VOLUME (smart/insider buy-sell bars per outcome + price) |
 TRADES (price lines with smart/whale/insider trade markers); per outcome: price, Market Certainty Index (MCI), bid/ask, volume, indicator
 bars, Order Book Depth chart with "Cost to move the price up/down 10%", Smart Money trades table, Whale Trades table, Potential Insiders table
 (user, z-score, invested, avg price, PnL, positions), Top Holders | Recent Trades tabs (pager, "Show 10").
Top Traders tooltip: "Smart Score measures a trader's historical accuracy weighted by position size and consistency." Filters popover: Smart
Score, Win Rate, Markets, PnL, Invested min/max, Clear / Apply (not applied).
Clicking a wallet opens "User Analysis" (Share / Watch not pressed): overall PnL, invested, position value, win rate, Smart Score label;
Realized PnL & Invested chart; "By category" radar + table; Positions Open/Closed with filters; Finished Trades bubble chart (buy vs sell
price); PnL Distribution histogram (median, mean, skew, PF); Risk vs Return scatter; Smart Score & Win Rate history.
