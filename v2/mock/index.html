RevenueChaser v2 — design mock

Step 2 of the v2 run plan. Fincept Terminal's visual structure (frame rows, panel anatomy, freshness contract, tile and judgement-card patterns) on our own theme: Mürekkep light, Gece dark, Inter with tabular numbers, the 4 px spacing scale and our token names. No Fincept code, string, image or asset is used; the structure was measured on a read-only walk and written again from scratch.

Every figure on these screens is illustrative. Nothing here is read from the live store, and the Portfolio screen in particular carries no real position, balance or account id. Numbers are shaped like ours so the layout can be judged; they are not ours.
Web is drawn for the desktop only — 1187 px (laptop) and 1884 px (extra screen), light and dark, as avo decided on 21 Nov 00:41 ("A. Hayır, telefon APK'da"). The phone view is the native Android app, so no 412 px web layout is drawn. This page itself scales to fit any screen, so the mock reads on a phone.
